Build a complete Morpheus demonstration without writing JSON

Leroy builds a demonstration tenant on an empty HPE Morpheus 9 appliance: the organization, roles and personas, environments, groups, policies, automation and a self-service catalog. No cloud integration required. Design what you want to show here, download the manifest and apply it with a single command. When the demonstration is over, Leroy removes exactly what it created.

How it works

Four steps, from this screen to the appliance.

  1. 1

    Pick a scenario

    Standard platform, regulated banking, multi-brand retail, telco and edge, or public sector. Each one fills in a whole demonstration; from there you adjust whatever you want.

  2. 2

    Design it on the canvas

    Every box is a block of Morpheus resources and the lines are the real dependencies: the tenant role before the tenant, the users inside it, the policies over the groups, and the input and the task inside the workflow the catalog exposes. Drag the boxes, switch off whatever the customer does not need, and edit personas, permissions, environments, groups, policies and automation.

  3. 3

    Download the manifest

    A schema 2 JSON document, validated against the same rules the CLI applies. It never contains passwords or tokens, so you can keep it in the customer's repository or send it by email without risk.

  4. 4

    Apply it with the CLI

    plan shows what will happen without touching anything, apply builds it and can be resumed if interrupted, verify --deep logs in as each persona to check permissions and runs the workflow, and destroy removes only what Leroy created.

Install the CLI

A single bash script. No installer, no packages and no administrator rights.

Download with curl
curl -fsSL https://raw.githubusercontent.com/da3m0nsec/leroy/main/leroy.sh -O && chmod +x leroy.sh
Or with wget
wget -q https://raw.githubusercontent.com/da3m0nsec/leroy/main/leroy.sh && chmod +x leroy.sh
Connect to the appliance
export MORPHEUS_URL="https://morpheus.example.com"
export MORPHEUS_API_TOKEN="your-administrator-token"
./leroy.sh status
Apply the manifest you designed
./leroy.sh demo plan   --file my-demo.json
./leroy.sh demo apply  --file my-demo.json
./leroy.sh demo verify --file my-demo.json --deep

Requirements

  • Bash 4.4 or newer, curl and jq.
  • An HPE Morpheus 9 appliance and a Master Tenant administrator token.
  • The token is read from MORPHEUS_API_TOKEN and is never passed as an argument, because process arguments are visible to other users. A .env next to the script works too, and is read without sourcing or exporting.
  • TLS verification is off by default for appliances with internal certificates. Set MORPHEUS_VERIFY_TLS=true when the certificate is trusted.

Run ./leroy.sh with no arguments to open the terminal interface, with a status dashboard, component selection, a preview before building, and protected destruction.

What it deploys

Seven blocks you switch on and off independently. Dependencies hold themselves: policies need groups, the catalog needs automation, and persona roles travel with the tenant.

Multitenancy

A demonstration organization of its own with its account role. Switch it off and the rest of the content is created in the Master Tenant.

Roles and users

The personas of the demonstration. Each one produces a role, a password held in Cypher and a user, with the permissions you define for it.

Environments

Environment labels such as development, staging and production, used when provisioning instances and applications.

Groups

Infrastructure groups to govern, with no need for an integrated cloud.

Policies

Message of the day, instance naming, expiration and Cypher access, applied to the tenant or only to the groups.

Automation

An input, a local Groovy task and an operational workflow that run on the appliance itself.

Catalog

A self-service item backed by that workflow, granted to the personas you choose.

Security

The manifest carries no credentials

Persona passwords are generated by Morpheus Cypher at apply time. They are not written to the manifest, to local state, or to logs. Validation rejects a manifest containing password, token or access_token keys.

It only removes its own

Every resource Leroy creates carries an ownership marker. destroy checks local state and that remote marker before deleting anything, and stops if the two disagree.

This page is static

The builder runs entirely in your browser. There is no server, no analytics and no calls to Morpheus. What you design stays in your browser until you download it.

Built for demonstrations

Use a least-privilege service account and a demonstration appliance. This is not intended for production.
